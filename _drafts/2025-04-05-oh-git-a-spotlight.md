wanted to show off some work that I invest in doing on my Git history which
made their life as a code reviewer easier: Currating my Git commits.

I never had a good demo of the value of this beyond my own workflows. I've
_known_ it was valuable to others, and a worthy use of time, but I had never
seen someone show in a concrete and quick demo the actual value.
